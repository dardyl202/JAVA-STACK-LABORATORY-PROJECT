# JAVA-STACK-LABORATORY-PROJECT
Project about stack in Data Structure CN48143

Project Description.
This project demonstrates the stack data structure using Java. It shows how stack operations work, following LIFO or Last In, First Out princeple.

Push: Adds an item to the stack.
Pop: Removes the top item from the stack.
Peek: Shows the top item without removing it.
Clear: Removes all the values from the stack.
Check Stack: Checks the current contents or status of the stack.
Random: Generates random values to demonstrate stack operations.
Stack Capacity: Supports up to 10 values and displays the current size of the stack.
Status Message: Shows messages to guide users when performing stack operations.
Input Field: Allows users to enter a value before pressing the Push button.
